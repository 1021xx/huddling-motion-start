# 영상 표현의 재량 · 공간과 연결

## 적용 범위

[브랜드 고정 규칙](brand-rules.md)과 사용자 조건 안에서 구성·배치·크기·여백·원근·카메라·곡선·동작 길이·편집 박자는 제작자가 설계한다. UI 토큰과 기존 시안의 숫자는 선택 가능한 재료이지 영상 연출의 한계가 아니다.

새 값은 해당 영상의 VALUES.md에 `대상 / 값 / 목적 / 브랜드 토큰 또는 연출 선택 / 검수 결과`로 기록한다. 실제 UI 위치에서 계산돼야만 영상 좌표가 허용되는 것은 아니다. 정렬·여백·가독성으로 배치의 타당성을 설명한다. 단순 좌표 전체를 승인 목록으로 만들지 않는다.

## 1 참고한 표현 원리

- 한 화면의 주인공을 분명히 한다. 피사체를 크게 보여주고, 여백으로 시선을 모은다.
- 같은 대상의 각도·거리·보이는 범위를 바꾸면서 정보를 공개한다. 매번 새로운 화면을 등장시키는 방식에 의존하지 않는다.
- 여러 요소의 층이 분리되고 다시 정리되는 움직임으로 관계를 보여준다.
- 움직임은 다음 정보로 시선을 넘기는 역할을 한다. 장식적인 흔들림·반복 부유·과도한 바운스를 추가하지 않는다.

위 항목은 참고한 시각 표현의 원리다. 아래 타이포·색·수치는 서비스 영상에 맞춰 적용한 제작 선택이며 외부 영상의 측정값이 아니다.

## 2 서비스 영상에 적용할 디자인

### 구도와 여백
- 중심 피사체, 짧은 헤드라인, 필요한 보조 정보 순으로 위계를 잡는다.
- 상단 설명·고정 로고·부제·카드·캐릭터를 매 장면에 모두 넣지 않는다.
- 폰 왼쪽/설명 오른쪽, 중앙 제목/하단 카드 등 하나의 구도를 전 장면에 반복하지 않는다.
- 원본 카드·캐릭터·로고를 선택적으로 주인공으로 삼고, 전후 장면의 크기와 배치에 대비를 만든다.

### 깊이와 재질
- 밝은 중성 배경과 부드러운 그림자로 카드의 앞뒤 관계를 드러낸다.
- 원근과 회전은 카드 관계·시선 전환을 설명하는 데 사용한다. 핵심 정보를 읽는 순간에는 읽기 좋은 각도로 정착시킨다.
- 원본 UI 내부 스타일은 보존한다. 영상용 그림자·원근·광원은 바깥 wrapper에 적용한다.
- 브랜드 색을 바탕으로 만든 입체 그래픽은 사용할 수 있다. 실제 서비스 UI와 영상용 설명 그래픽은 구분한다.
- 굵은 밑줄, 큰 단색 화면 전환, 작은 캐릭터 장식을 기본값으로 반복하지 않는다.

### 타이포그래피
- Pretendard와 기존 굵기 체계를 유지한다. 제목은 짧게 쓰고 장면 안의 정렬 축을 일관되게 잡는다.
- 같은 축의 단어 교체, 마스크 리빌, 피사체와 연결된 위치 변화 등 의미에 맞는 방법을 선택한다.
- 모든 문구에 동일한 상승/하강을 적용하거나, 크기만 키워 강조하지 않는다.
- 읽을 문구가 정착하면 다음 요소로 움직임을 넘긴다. 보조 문구는 짧게 줄이고 충분히 읽을 시간을 준다.

## 3 움직임과 편집

- UI 피드백 규칙과 영상 연출 규칙을 구분한다. 16px/240ms 등 작은 UI 등장값만으로 전체 영상을 구성하지 않는다.
- 약 1초는 초점을 넘기는 박자의 참고다. 모든 컷을 정확히 1초로 자르거나 모든 요소를 끊임없이 움직이라는 뜻이 아니다.
- 한 요소가 끝나기를 기다린 뒤 다음 요소를 시작하는 직렬 구성을 반복하지 않는다. 의미 있는 겹침과 연속 상태를 설계한다.
- 원근 변화, 대상 확대, 같은 방향 이동, 층 분리/결합을 상황에 맞춰 조합한다. 장면마다 서로 다른 효과를 무조건 넣지 않는다.
- 읽기 시간과 엔딩의 정착 시간은 확보한다. 몇 초짜리 동일 구도 정지가 생기면 내용·편집 이유를 검수한다.
- 장면 순서와 좌표는 영상별로 설계한다. v2의 장면 구성 자체를 고정 템플릿으로 복사하지 않는다.


## 참고와 검수

## 피드백으로 보완한 제작 규칙

- 버튼에서 줌인하는 전환은 실제 클릭한 버튼을 확대해 시작한다. 별도 사각형을 화면 좌표로 대충 맞춰 덮지 않는다. 전환 레이어가 필요하면 버튼의 실제 경계·둥근 모서리·변환 상태와 첫 프레임이 정확히 일치해야 한다.
- 승인 표현을 큰 체크 원과 컨페티로 고정하지 않는다. 이번 피드백에서는 둘을 제거하고 단어가 교대·결합·강조되는 타이포로 상태 완료를 표현한다. 다른 영상에서도 효과를 넣기 전에 문구 자체의 표현 가능성을 검토한다.
- 엔딩은 정지 이미지를 남은 시간만큼 유지하지 않는다. 로고 확대 → 문구 공개 → 핵심 단어 강조처럼 브랜드와 메시지가 연결되는 동작을 설계하고, 불필요한 잔여 시간은 줄인다. 움직임을 유지하려고 목적 없는 반복을 추가하지 않는다.


- 모든 주요 모션은 정보 강조·사용자 행동·상태 변화·장면 연결 중 어떤 역할인지 설명할 수 있어야 한다. 역할이 없는 반복 부유·회전·등장은 제거한다.
- 과감한 줌인·줌아웃·오버슈트는 허용한다. 진행률의 확대, 클릭 대상에서 다음 상태로 이어지는 전환, 승인 순간의 강조처럼 의미 있는 사건에 집중한다. 강조 후에는 읽을 수 있는 크기·각도와 정지 구간으로 정착한다.
- 클릭 연출은 커서의 목표 도달 → 버튼 눌림 → 상태 변화 순서로 연결한다. 커서가 버튼 밖에 있거나 클릭과 반응 시점이 어긋나지 않게 검수한다.
- 진행 바·퍼센트·완료 단계는 같은 진행 상태에 맞춘다. 최종 수치는 서비스 사실을 따른다. 50%·2/4는 이번 영상의 값이며 모든 영상의 고정값이 아니다.
- 카피는 화면에 보이는 행동·결과를 설명한다. 의미가 불분명한 문구로 빈 공간을 채우지 않는다. 타이포의 등장 속도와 정착 후 읽기 시간을 따로 설계한다.
- 승인·완료 같은 성취 순간에는 파티클·링·광원을 사용할 수 있다. 문구와 핵심 심볼을 가리지 않고, 사건이 끝나면 효과도 종료한다. 모든 장면에 축하 효과를 반복하지 않는다.
- 배경을 흰색으로 한정하지 않는다. 검정 배경과 브랜드 포인트 색을 상태 변화나 엔딩의 대비에 사용할 수 있다. 어두운 장면에서도 로고·글자 대비와 UI 원본의 사실성을 유지한다. 검정 엔딩 자체를 모든 영상의 필수 템플릿으로 만들지 않는다.
- 다른 접근을 요청받으면 기존 버전을 보존하고 별도 버전을 만든다. 새 연출의 존재를 사용자 최종 승인으로 기록하지 않는다.


구현값이 필요할 때 [v2 예시](motion-examples.md)를 참고한다. 동일한 카피·구도·전환을 반복하는 템플릿으로 쓰지 않는다. 결과는 [품질 검수](quality-review.md)로 평가한다.
