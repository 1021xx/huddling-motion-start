# 영상 연출 예시 — v2

아래는 제작한 시안의 값이다. 보편적인 필수값이나 외부 영상의 실측값이 아니다. 이 값은 재현용 예시다. 다른 영상에서는 목적과 가독성에 맞게 바꾸며 개별 수치 승인을 요구하지 않는다.

| 항목 | 구현값 | 용도 |
|---|---|---|
| 제목 | 112px / 140px, 600 | 짧은 주제 문구 |
| 엔딩 제목 | 112px / 145px, 600 | 두 줄 엔딩 |
| 보조 문구 | 33.6px / 44.8px, 400 | 짧은 설명 |
| 결과 강조 | 78.4px / 95.2px, 600 | 승인 결과 |
| perspective | 2200px | 카드 공간감 |
| 주요 이동 | 0.7–1.2초 | 카드 재배치·도착 |
| 도착 곡선 | power3.out / expo.out | 부드러운 정착 |
| 연결 곡선 | power3.inOut | 같은 대상의 구도 변화 |
| 퇴장 곡선 | power3.in | 다음 장면으로 가속 |
| 버튼 | 0.97배, 110ms → 1배, 240ms | 제출 반응 |
| 카드 회전 예시 | X 8·24·40도, Y -18·-14·-8·18·20도, Z -5·-4·-3·2·3·5도 | 진입·층 관계. 각 카드의 값은 다름 |
| 그래픽 회전 예시 | Y -75도 → 0도 | 새 입체 체크 그래픽 등장 |
| 배경 | #ffffff ↔ #f7f7f8 radial gradient | 밝은 공간감 |
| 입체 강조 | #3759de, 하이라이트 #6b84ed, 음영 #2946bb | 영상용 체크 그래픽 |
| 카드 그림자 예시 | 0 36px 72px -24px #18191b26, 0 4px 8px #18191b0a | wrapper 깊이 |

브랜드 기본색·폰트·UI 원본은 design.md를 따른다. 위 파생색·광원·그림자·타이포 크기는 시안의 연출값이며 서비스 UI 토큰을 대체하지 않는다. 새로운 연출값은 해당 영상의 VALUES.md에 목적과 함께 기록한다.
