# 브랜드·원본 고정 규칙

## 범위
이 문서는 브랜드 정체성과 서비스 사실을 보호한다. 영상의 좌표·카메라·편집·타이포 크기를 고정하지 않는다.

- 브랜드 기본색, 폰트와 굵기, 로고·캐릭터 원본은 [design.md](design.md)를 따른다.
- 로고를 글자로 다시 조판하거나 원본 형태·색을 임의로 바꾸지 않는다. 비율을 유지한 wrapper 확대·회전은 영상 연출이다.
- 서비스 화면·부품은 src의 원본과 실제 상태를 사용한다. 기능·진행률·수익·승인 상태를 임의로 만들어 실제 UI처럼 보여주지 않는다.
- 원본 UI 내부의 크기·간격·색·내용은 보존한다. 고해상도 캡처와 외부 wrapper의 배치·원근·그림자는 허용한다.
- 설명용 카피·도형·입체 그래픽·새 영상 자산은 사용할 수 있다. 실제 서비스 UI나 기능으로 오인되지 않게 하며 출처·역할을 기록한다.
- 기존 캐릭터와 로고를 대체하는 신규 브랜드 정체성은 별도 사용자 지시가 필요하다.
- 출력 규격·길이·음향 유무 등 사용자의 명시적 조건은 BRIEF를 따른다. 기본 출력은 video.md를 참고한다.

브랜드 변경, 서비스 사실 변경, 사용자 조건 변경이 필요하면 해당 사항만 확인한다. 영상 연출 수치가 기존 문서에 없다는 이유만으로 승인을 요청하지 않는다.
