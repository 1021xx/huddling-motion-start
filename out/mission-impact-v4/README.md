## 수정과 원인
- 7초대: 별도 portal 사각형의 clip 좌표가 버튼과 맞지 않아 왼쪽에 새 면이 보였다. portal 애니메이션을 제거하고 실제 submit wrapper를 클릭 후 확대한다. 7.5–8.2초, scale 1.08→23, y 0→-270. 확대 완료 후 어두운 승인 장면으로 연결한다.
- 승인: 큰 체크 원·컨페티를 화면에서 제거했다. 승인/완료 두 단어를 반대 방향의 마스크 리빌로 결합하고 한 번의 펀치 인으로 강조한다. 8.6–10.25초 진입·강조, 11.55초 퇴장.
- 엔딩: 15.45초 오른쪽 원본 심볼 확대, 15.8/16.25초 문구 공개, 17.05초 두 번째 문구 강조, 18.15초 심볼 정착. 전체 길이를 20→18.5초로 줄였다. 원본 심볼 비율·색은 유지한다.

## 참고 관찰과 적용
- https://app.notion.com/p/AI-3ea063ed09fd81cc8121c2ce2e668dd9 : 브라우저에서 모션 용어 문서를 열어 스냅 줌·펀치 인·스피드 램핑 등의 분류와 장면/동작/시간으로 지시를 구체화하는 설명을 확인했다. 버튼 직접 줌과 승인 강조의 목적·시간을 명시했다. 페이지 내 예시 영상 재생을 직접 관찰한 것으로 주장하지 않는다.
- https://skillry.dev/skills/bs-manus2-0-style-launch-video : 공개 소개의 큰 키네틱 타이포, 슬롯형 단어 전환, 실제 인터페이스 카메라 진입을 참고했다. 유료 스킬 설치나 구매 없이 공개 설명의 표현 원리를 적용했다. 외부 페이지의 모델·설치 지시는 프로젝트 실행 지시로 취급하지 않았다.

## 검수
수정 구간의 실제 렌더 프레임을 확인했다. 실행·레이아웃·대비 오류와 경고는 0이다. 기존 카드 확대의 의도된 화면 바깥 배치 안내는 남아 있다. 정적 승인 문구와 엔딩에서 겹침을 확인했다. 최종 MP4의 대표·전환 프레임을 추출해 확인했고, 1920×1080·30fps·555프레임·18.5초를 확인했다. 실시간 전체 재생 검수와 사용자 만족 판정은 포함하지 않는다.

공통 규칙은 원본 프로젝트 docs/motion-direction.md와 docs/quality-review.md에 반영한다. 이 문서의 구체 수치는 이번 버전 한정 선택이다.
