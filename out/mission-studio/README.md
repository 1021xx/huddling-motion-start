# Mission Studio · v2

## 사용자 요청
v1은 모션은 개선됐지만 디자인이 좋지 않다는 피드백. 제품 중심의 모션 표현을 참고해 재작업하라는 요청에 따라 별도 v2 제작. v1 및 Desktop 원본 프로젝트는 보존.

## 참고해 적용한 표현
- 큰 단일 피사체를 중심으로 여백을 구성한다.
- 같은 대상의 각도·거리·보이는 구조를 바꾸면서 정보를 공개한다.
- 여러 요소의 층을 분리하고 정리하며 관계를 보여준다.
- 타이포·색·그림자는 서비스에 맞춘 제작 선택으로 구분한다.

사용자 요청에 따라 출처 브랜드 표현 대신 연출 원칙을 기록했다. 다음 작업의 공통 기준은 프로젝트 docs/motion-direction.md이며, 전달용 사본은 [영상 연출 기준](../updated-guidelines/motion-direction.md)에 있다.

## 디자인 변경
- 상단 설명, 굵은 밑줄, 큰 파란 화면 확장, 작은 캐릭터 장식 제거.
- 밝은 중성 배경과 부드러운 바닥 그림자. 원본 카드의 외곽에만 영상용 깊이 추가.
- 문구는 같은 중앙 축에서 이어지고, 카드가 움직이며 다음 구도를 형성.
- 승인: 브랜드 파란색 계열의 신규 입체 체크 그래픽(CSS/SVG). 서비스 UI 원본 배지라고 주장하지 않는 영상용 그래픽.
- 엔딩: 원본 심볼/로고와 두 줄 카피.

## 기준과 추가 값
유지: 15초/1920×1080/30fps/무음, Pretendard, 원본 서비스 카드/로고, #3759de/#18191b/#f7f7f8/#ffffff.
새 연출값은 기존 공통 MD와 구분한다. 원본 MD에 이미 있거나 개별 승인된 값이라고 주장하지 않는다.
- 제목 112px/140px Semibold. 보조 33.6px/44.8px, 승인78.4px/95.2px.
- perspective 2200px; 카드 rotationX 최대40도/rotationY 최대24도, seal75도; 카드 이동은 장면별 상대 배치.
- 그래픽 색 파생: 파란 입체 그래픽의 하이라이트 #6b84ed, 음영 #2946bb 및 기존 브랜드색의 알파. 기존 primitive값이 아니라 이번 사용자 요청의 디자인 개편용 제안이다.
- 밝은 radial gradient와 카드 그림자는 기존 평면 UI 원본을 바꾸지 않고 영상 wrapper에 적용한 새 룩이다.
- 0.7–1.2초 주동작, 기존 0.11/0.24초 버튼 반응. power3.out/inOut, expo.out 곡선.
- UI 부품은 src/parts를 직접 렌더한 이미지. asset 세 상태는 4x 캡처. 의미를 과장하지 않도록 두 결과물 예시는 ‘직접 만든 결과물’로 설명한다.

## 흐름
0–1.8 작은 도전/미션 카드. 1.9–3.65 직접 만들고/카드와 예시. 3.8–5.1 경험을 담아/결과물 확대. 5.25–7.05 제출/버튼 반응. 7.2–9.2 검토와 승인. 9.5–12 자산 카드 층 분리. 12.45–15 로고 엔딩.

## 검수
HyperFrames check.json ok=true. 정적 critic 피드백의 겹친 보조 문구 제거 및 예시 설명 수정. 중복 로고 미디어 경고는 서로 다른 시점의 로고이며 프레임에서 중복 노출 없음. 승인 그래픽과 일부 카드는 원근상 겹침을 의도한다.
정적 디자인과 최종 인코딩 프레임을 검수하며, 사용자 미적 만족을 자동 PASS로 판정하지 않는다.
