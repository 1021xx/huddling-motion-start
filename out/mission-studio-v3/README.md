# Mission Studio v3

## 요청 반영
- 제출 버튼: 실제 커서 접근, 눌림, 복귀, 짧은 클릭 링. 커서의 눌림과 버튼의 눌림이 같은 시점에 시작한다.
- 첫 미션 카드: 정적 캡처 대신 원본 src/parts/mission-card.html의 구조·스타일을 재사용. 진행 바와 텍스트를 0%/0단계에서 원본 50%/2단계로 올린다. 실제 라이브 데이터가 아닌 진행 표현이며 원본 최종 상태를 넘지 않는다.
- 카피: ‘실제 적용 사례와 함께 제출해요.’
- 타이포: 145px 빠른 이동에서 55px 이동+점진적 등장으로 변경. expo 도착을 power2.inOut로 변경. 주요 글자 등장 0.9초에 전체 1.25배 시간 확장을 적용해 약1.125초. 짧은 카피의 정착 시간을 확보.
- 승인 강조: 체크 드로잉 완료 시점(10.625초)에 컨페티 32개와 얇은 확산 링이 시작. 중심 그래픽 뒤에서 주변으로 퍼지고 약1.3초 안에 정리. 청색 중심에 소량의 금색. 반복 없음.
- 전체 길이: 19초/1920×1080/30fps/무음. 사용자의 속도 조정 요청에 따라 길이를 늘린다고 작업 중 알렸다.

## 기존 편집 유지
v2의 최신 소스에서 시작했다. 사용자가 미리보기에서 이동한 보조 문구 translateY 99.453px와 승인 그래픽 y44.201px를 보존했다. 승인 퇴장의 편집 키프레임에 있던 짧은 y0 복귀만 제거해 위치 점프를 방지했다. v2 파일은 변경하지 않았다.

## 구현과 검수
- 원본 UI의 모든 px를 동일 배율 2.2로 환산해 표시한다. wrapper scale의 작은 글자 대비 판정 문제를 해결하면서 출력 비율·색·서체·간격을 유지했다.
- 진행 텍스트는 임의 시점 탐색에서도 같은 결과가 나오도록 타임라인 set으로 기록했다. 단계 수는 floor(퍼센트/25), 50%에서2/4.
- 컨페티 궤적은 인덱스 기반 고정 수식. 난수·타이머·무한 반복 없음.
- check.json: ok=true, 런타임/레이아웃/대비/craft 오류0. 같은 로고를 다른 시점에 쓴 중복 미디어 경고1.
- 스냅샷에서 1.2초9%/0단계, 2.2초34%/1단계, 3.1초50%/2단계 확인. 커서 접근/누름과 컨페티 분산 프레임 확인.
- 자동 검사와 프레임 검수는 사용자 만족을 대신하지 않는다.
