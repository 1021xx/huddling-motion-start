# BRIEF — 미션 참여

- 사용자 확정: `1. b / 2. 15초 / 3. 기존 레퍼런스`.
- 목적: 이번 달 미션 확인 → 결과물·적용 사례 제출 → 검토 후 승인이라는 참여 과정을 이해시킨다.
- 전체 길이: 15초. 출력과 룩은 `docs/video.md` 참조.
- 주 레퍼런스: Remotion Prompts — Apple-Style Device Rise Animation. 기존 선택지에서 고지한 문서 기반 진행에 동의한 것으로 기록한다.
- 보조 레퍼런스: Carbon Design System — Motion. 서비스의 `docs/motion.md`로 옮긴 토큰을 사용한다.
- Skillry 영상은 접근 불가 상태이므로 이 영상의 분석·평가 근거에서 제외한다.
- 자산: `src/screens/03-mission.png`, `src/screens/04-approved.png`, `src/parts/mission-card.html`, `button-submit.html`, `badge-approved.html`, `logo.html`.
- 별도 영상 문구는 서비스 원본의 의미를 요약한다. 새 UI나 실제 서비스에 없는 완료·처리 상태는 만들지 않는다.
- 제출과 승인은 시간 경과를 생략한 개념 설명이다. “검토 후”라는 영상 문구로 즉시 승인 오해를 방지한다.
- 음성·음악은 요청되지 않았으므로 이번 장면표는 무음 기준이다.
- 상태: BRIEF·장면표 A·읽는 시간 규칙 확정 / 스냅보드·미리보기 확인 / 사용자 `렌더링하자` 승인 / 최종 MP4 생성·표본 검수 완료. 결과: mission-entry.mp4.
