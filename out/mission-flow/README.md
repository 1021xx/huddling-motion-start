# 미션이 내 자산이 되는 순간 · 새 접근 v1

15초 · 1920×1080 · 30fps · 무음. 원본 프로젝트를 보존하고 별도 폴더에서 제작했다.

## 요청과 작업 범위
2026-10-29 사용자: “응 그럼 한번 새로운 접근으로 모션 영상 만들어줘.”
추가 요청: “필요하다면 새로운 자산 사용해서 영상 꾸며줘도 좋아. 기준에 맞춰서”
앞선 제안의 큰 글자/약1초 박자/연속 전환을 실제 영상으로 제작하라는 지시로 해석했다. 별도 정적 시안 승인이나 개별 수치 승인을 받았다고 기록하지 않는다. 기존 스킬의 중간 승인 절차 대신 사용자의 이번 제작 지시와 앞선 접근 제안을 근거로 시안 MP4까지 진행했다.

## 유지한 기준
- Pretendard 400/600/700, 자간 0, 원본 로고/캐릭터/서비스 UI
- 색: 흰색 #ffffff, 텍스트 #18191b, 브랜드 #3759de, 틴트 #edf1ff
- 15초, 1920×1080, 30fps, 기존 무음 조건
- 서비스 UI는 원본 src/parts HTML을 Chrome에서 3배 픽셀 밀도로 캡처했다. _check 비교 이미지를 쓰지 않았다.

## 이번 시안에 추가한 연출값
이 항목은 기존 공통 MD에 원래 있던 값이 아니다. 새 접근을 구현한 시안용 값으로 기록한다. 원본 docs는 변경하지 않았다.
- 타이포 주연: 기존 video-display 78.4/95.2px를 2배(156.8/190.4px)로 적용. 보조 문구는 기존 33.6/44.8, 42/67.2 체계 유지.
- 시작 글자 → 장 제목: 0.5배, (-230,-140) 이동. 카드 상단 좌표와 정렬하기 위한 영상별 배치.
- 기본 전환: 700ms, 강조 400ms, 불투명도 240/150ms, 버튼 반응 110ms. 기존 duration 수치 재사용.
- 이동 곡선 power3.inOut, 타이포 도착 expo.out, 리빌 power3.out. 기존 UI 곡선과 구분한 영상용 곡선.
- 화면 릴레이 이동: 1920px(출력 폭). 카드 이동 -330px(중앙 x610에서 왼쪽 x280으로 정렬).
- 버튼 반응: 0.96배 → 1배. 버튼 위치(610,600,700,88)에서 파란 화면으로 mask 확장.
- 캐릭터: 오른쪽 300px에서 진입, 8도→0도 정착. 원본 bitmap 변형 없이 wrapper에 적용.
- 그래픽 자산: 원본 파란색의 선/면, 흰색 전환 면. 별도 AI 생성 이미지나 외부 자산은 사용하지 않았다.
- 화면 배치는 1920×1080의 장면별 아트디렉션. UI 내부 크기/스타일은 원본 캡처에 보존된다.

## 구성과 연결
| 시점 | 행동 |
|---|---|
| 0–1.8 | ‘미션’ 가로 리빌 → ‘해볼까?’ 글줄 리빌 → 짧은 보조 문구 |
| 1.8–2.7 | 같은 ‘미션’ 글자가 상단 제목으로 작아지며 이동. 밑줄이 확장되고 미션 카드가 드러남 |
| 2.95–5.15 | 카드가 왼쪽으로 이동. 오른쪽에 ‘결과물 하나’ → + → ‘실제 적용 사례’ |
| 5.15–7.1 | 같은 방향의 화면 이동으로 제출 장면 연결. ‘제출.’ 강조와 버튼 반응 |
| 7.1–8.85 | 버튼의 파란 면이 화면 전체로 확장. ‘검토를 거쳐’ 리빌 |
| 8.85–10.6 | 흰색 면이 가로로 열리며 승인 문구, 원본 배지, 원본 캐릭터 등장 |
| 10.6–12.05 | 승인 장면의 이동 방향을 이어받아 내 자산 카드 등장 |
| 12.05–15 | 틴트 면이 엔드 카드로 이어지고 두 줄 타이포, 로고, 캐릭터 정착 |

1초마다 모두 잘라내는 방식 대신 0.7~1초 안팎으로 다음 주의 대상을 넘기는 방식이다. 카드 전체 설명을 1초에 읽으라고 요구하지 않고 핵심 의미를 별도 큰 글자로 전달한다.
