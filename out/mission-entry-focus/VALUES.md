# 값과 원본 근거

출력 1920×1080은 docs/video.md. title-safe 80%는 HyperFrames format 계약으로 좌우 192, 상하108.
색·폰트·부품 스타일은 docs/design.md와 src/parts 원문. 원본 parts는 추출해 재사용하며 내부 크기는 유지.
헤드라인 78.4/95.2는 video-display, 본문42/67.2는 video-body, 라벨30.8/44.8은 video-eyebrow.
원본 카드 350×253을 2배(기존 영상 정적 배율)로 700×506 표시. 오른쪽 끝1728=1920−192. 시작1028=1728−700, y248은 제목 기준선과 정렬.
제출 버튼 350×44, 승인배지108×32를 video-text-scale 2.8로 균일 정적 표시. 버튼980px는 가운데 (1920−980)/2=470, 배지302.4px는 (1920−302.4)/2=808.8.
수직 위치는 문구 블록과 부품이 겹치지 않도록 제목/본문 행간 합, 중심 정렬, 안전영역에 맞춘 장면 배치이다. 공통 디자인 토큰으로 등록하지 않는다.
로고는 원본149×19를 기존2배로298×38, 좌측 안전영역192와 하단 안전영역108에 정렬.
스냅보드에는 애니메이션·카메라·scale tween 없음. 정적 wrapper 확대는 동적 확대가 아님.
