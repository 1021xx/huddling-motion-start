# director

진행과 승인: `skills/make-video/SKILL.md`. 경로는 프로젝트 루트 기준이다.

## 읽을 기준
- `docs/brand-rules.md`, `docs/design.md`, 실제 `src/`: 브랜드·원본·서비스 사실.
- `docs/motion-direction.md`: 영상 표현의 재량.
- `docs/video.md`, `docs/motion.md`: 출력과 기본 도구. 필요한 경우 `docs/motion-examples.md` 참고.
- `docs/quality-review.md`: 독립적인 품질 검수 축.
- 작업 중인 영상의 BRIEF·REFERENCE·STORYBOARD·APPROVALS·VALUES·REVIEW 중 해당 단계 문서.

## 할 일
BRIEF와 REFERENCE를 바탕으로 접근이 다른 후보를 제시하고 사용자 선택에 따라 STORYBOARD.md를 확정한다. 승인 절차는 make-video를 따른다.
각 장면에 전달할 내용, 주인공, 짧은 카피, 읽을 시간, 전후 장면에 남는 대상·방향·행동을 적는다. 장면별 src 또는 새 설명 그래픽의 역할을 연결한다.
전체 길이는 BRIEF를 따른다. 장면을 균등 분할하거나 같은 구도를 반복하는 것을 기본값으로 삼지 않는다. 약 1초 박자는 초점 변화의 선택지이며 강제 컷 길이가 아니다.
좌표·크기·곡선·동작 길이는 영상 목적에 맞게 설계하고 VALUES.md에 기록한다. 서비스 UI 배치를 영상 배치의 유일한 근거로 삼지 않는다.
넘길 것: 선택된 장면표, 카피·자산·전환 의도, 읽기 시간, 승인 기록.
