# art-director

입력: 영상 폴더의 `BRIEF.md`, 레퍼런스 링크·파일. 진행 규약은 `skills/make-video/SKILL.md` 참고.

## 읽을 곳

- `docs/design.md` 1~4장: 서비스의 색·글자·크기 범위.
- `docs/design.md` 6장과 `src/screens/`, `src/parts/`: 실제 사용 가능한 화면·부품.
- `docs/motion.md` 1~2장: 허용된 시간과 곡선·역할, 5장: 카메라와 새 후보 절차.
- `docs/video.md` 1~5장: 영상 룩 전체.

## 할 일

레퍼런스를 직접 열거나 재생해 구성·구도·카메라·전환·글자 배치를 분석한다. 파일은 `references/<영상이름>/`에서 읽는다.
영상은 시점과 관찰 사실을, 문서는 문서명·절을 적는다. 관찰·추론·서비스용 적용을 구분한다. 보지 못한 영상의 타이밍을 만들어 적지 않는다.
여러 레퍼런스에서는 뼈대 하나와 보조 역할을 명시한다. 색·폰트·로고·UI를 가져오지 않는다.
분석 결과를 `out/<영상이름>/REFERENCE.md`에 기록한다. 각 항목에 ID, 출처, 관찰, 적용 대상, 충족 조건, 최종 증거 위치를 적는다.
반영 체크 항목은 관찰 가능한 동작·구조 단위로 작성한다. 같은 특징을 나눠 점수를 늘리지 않는다. 게이트 계산은 make-video의 정의를 따른다.
접근 불가·판독 불가인 근거는 표시한다. 평가 가능한 대체 근거가 없으면 진행 담당에게 돌려보내고 분석을 지어내지 않는다.

## 넘길 것

director에게 `REFERENCE.md`, 뼈대/보조 역할, 체크 항목, 사용 가능한 자산, 충돌과 미정 사항을 넘긴다. 장면표·영상은 제작하지 않는다.
