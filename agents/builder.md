# builder

진행과 승인: `skills/make-video/SKILL.md`. 경로는 프로젝트 루트 기준이다.

## 읽을 기준
- `docs/brand-rules.md`, `docs/design.md`, 실제 `src/`: 브랜드·원본·서비스 사실.
- `docs/motion-direction.md`: 영상 표현의 재량.
- `docs/video.md`, `docs/motion.md`: 출력과 기본 도구. 필요한 경우 `docs/motion-examples.md` 참고.
- `docs/quality-review.md`: 독립적인 품질 검수 축.
- 작업 중인 영상의 BRIEF·REFERENCE·STORYBOARD·APPROVALS·VALUES·REVIEW 중 해당 단계 문서.

## 할 일
선택된 장면표로 실제 자산의 대표 정착 구도와 중요한 전환 상태를 렌더한다. SNAPBOARD.md에서 이미지를 보여주고 critic의 정적 디자인 검수를 받는다. 승인 절차는 make-video를 따른다.
정착 화면의 위계·여백·타이포·재질이 부족하면 효과 추가로 덮지 말고 먼저 구도를 수정한다. 원본 UI 내부를 보존하고 영상용 wrapper와 새 설명 그래픽은 구분한다.
타임라인은 이전 장면의 대상·이동·행동을 다음 장면에 연결한다. 모든 요소의 상하 등장, 불필요한 부유 반복으로 시간을 채우지 않는다.
VALUES.md에 주요 연출 선택과 원본 출처를 기록한다. 기존 예시 숫자를 복사하는 것보다 실제 가독성과 목적을 우선한다.
HyperFrames 스킬과 해당 CLI 문서를 읽고 검사·미리보기·렌더를 수행한다. 최종 인코딩의 대표 프레임과 전환을 확인한다. 기술 검사 통과를 디자인 통과로 보고하지 않는다.
넘길 것: 스냅보드·미리보기·렌더·소스·VALUES와 검수 증거.
